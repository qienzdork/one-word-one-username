# One Word, One Username, One Reward

Entry for the make.fun bounty "One Word, One Username, One Reward"
(`u-rusdyxbt-one-word-one-username-one-reward-1a191fae`).

The program writes one text — the entrant's own make.fun handle,
`qienz-dork` — to `/output/entry.txt`. The judge's brief ranks a genuine
make.fun username first, so the entry is the real handle, sent as a single
word with no explanation, no links, and no pitch.

Run it with `python3 main.py`. Set `OUTPUT_PATH` to write elsewhere.
Deterministic, stdlib only, no network, no randomness.
